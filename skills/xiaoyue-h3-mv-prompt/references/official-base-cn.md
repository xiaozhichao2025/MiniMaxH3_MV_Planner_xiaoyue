# MiniMax H3 基础模式中文执行规范

本文件按照 MiniMax 官方 `base-en.txt` 的逻辑整理。它改变的是描述语言，不改变官方协议：字段名、标签、图片对齐固定句、时间格式与枚举值继续使用英文；字段内的实际画面和声音描述使用简体中文。

## 模式与固定结构

- T2VA：直接输出三个核心字段。
- I2VA：第一行必须原样采用官方首帧对齐句：`For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.`
- FL2VA：第一行使用官方首尾帧对齐句，`Picture 1`、`Picture 2`、`Shot N` 和 `S.SS-second` 按真实数据替换，其余固定英文不翻译。
- L2VA：第一行使用官方尾帧对齐句，真实替换 `<Picture 1>`、`[Shot N]` 和 `S.SS-second`，其余固定英文不翻译。

图片对齐句之后空一行，再按固定顺序输出：

```text
integrated_multimodal_description: [Shot 1] 中文镜头描述……

overall_soundscape: 中文环境声、动作声和非语言人声描述……

non_diegetic_music: 中文非剧情内配乐描述，或 N/A
```

## 时间线与镜头

- `[Shot 1]` 没有时间戳；后续镜头使用 `[Shot N] At MM:SS.mmm, ...`，其中固定标签和 `At` 保持英文，逗号后的描述使用中文。
- 普通切镜、叠化、淡入淡出或擦除只在 Planner 明确指定时出现；不得在单镜生成窗口里擅自增加切镜。
- I2VA 从首帧中的人物身份、服装、构图、场景和空间关系继续发展。
- FL2VA 写清首帧状态、可观察的中间变化以及如何逐步落到尾帧，不得只重复两张静态图片。
- L2VA 先推导兼容的开场状态，再让人物、物体、相机和环境逐渐收敛到指定尾帧。

## 中文镜头描述要求

按播放顺序写清：视觉风格、初始构图、主体外观与位置、场景和关键道具、动作与反应、运镜类型／幅度／速度、结束状态及同期声音。运镜用自然中文句子表达，例如“镜头以小幅度缓慢推近”，不要在句尾堆叠英文运镜标签。

## 人声、歌词与画面文字

- 发声者稳定使用 `(S1)`、`(S2)`；相同人物跨镜头保持同一编号。
- 对白或歌词只写在 `<d>[Language] 原文</d>` 中，`Language` 使用英文语言名，原文不翻译、不润色、不补写。
- 跨切镜连续的人声使用 `<scenetrans>` 并用中文说明声音无缝跨越切点；结尾被截断使用 `<cutoff>`。
- 旁白要明确为画外音，并说明画面人物嘴唇保持闭合。
- 只有真实存在于场景内的标牌或文字才可描述；本项目默认禁止字幕、歌词排版、卡拉 OK 字和标题卡。

## 声音字段

`overall_soundscape` 用连续中文段落概括环境声、动作声和非语言人声，不重复对白与歌词。只有用户明确要求完全静音才写 `N/A`。

`non_diegetic_music` 用中文描述角色听不到、只有观众听到的配乐，重点写乐器、速度、节奏与动态变化；没有非剧情内配乐时写 `N/A`。本项目最终以母带替换生成音轨，不得编造与母带冲突的新主旋律或人声。

## 中文示例

```text
integrated_multimodal_description: [Shot 1] 真人电影质感，中景构图中的短发女子站在雨夜站台边缘。镜头以小幅度缓慢向右跟移，她抬眼望向驶离的列车，深蓝外套下摆被风吹起，动作在灯光掠过面部后停住。

overall_soundscape: 细雨持续敲击金属站棚，远处列车摩擦声逐渐减弱，衣料和脚步声贴近画面主体。

non_diegetic_music: N/A
```
