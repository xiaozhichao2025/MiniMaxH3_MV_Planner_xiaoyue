# H3 MV 镜头、表演与连续性写法

本文件吸收 MiniMax 官方 `music-video-subtitle-generator` 中与 MV 镜头有关的部分，明确删除歌词上屏、动态字幕和 Typography 工作流。

## 音乐驱动原则

先理解这一窗口在整首歌中的位置：前奏、主歌、预副歌、副歌、桥段、间奏或尾奏。结合 BPM、重拍、能量曲线和歌词 cue，选择一个清楚的表演目标，不要把每一拍都变成新动作，也不要把每一句歌词都直译成道具或文字。

一个短镜头优先包含：

- 一个主表演动作或情绪变化。
- 一个清楚的主体与空间关系。
- 一种主要运镜，必要时带轻微速度变化。
- 一个能落在重拍、句尾或呼吸点的动作完成点。

音乐能量低时可用更长停留、较慢推拉、细微表情和环境运动；能量上升时增加身体幅度、前景穿越、镜头速度或构图变化。快速节奏不等于无意义摇晃或每拍切镜。

## 演唱和表演

- 人物真实演唱且嘴部可见时，按当前歌词片段描述口型、呼吸、眼神和身体力度，保证动作能在窗口内完成。
- 说唱可强调重音对应的手势、躯干反弹和视线攻击性，但不要逐字打手势。
- 非演唱人物只对音乐做表演反应，不要给他分配歌词或 `(Sx)`。
- 器乐段不编造歌词；使用舞蹈、环境、乐器演奏、移动表演或叙事动作。
- 若母带歌词只是背景声而没有具体人物在画面内演唱，按官方音频引用方式处理，不凭空制造说话者。

`<d>[Language] ...</d>` 只承载真实可听文字。它不是字幕指令；画面中仍然不得出现歌词、字幕或卡拉 OK 字。

## 镜头表达

描述顺序优先为：风格与光线 → 初始构图 → 主体外观和位置 → 动作与反应 → 运镜方向、幅度和速度 → 结束状态 → 同期声音。不要堆砌相互冲突的镜头运动。

镜头切换必须服从 Planner。不要在一个单镜头生成窗口里擅自加入额外切镜，除非当前镜头提示词明确要求 H3 内部多镜头。多镜头时，首镜用 `[Shot 1]`，后续镜头用官方 `[Shot N] At MM:SS.mmm, ...`。

## 三种边界

### `hard_cut`

前后镜头独立生成。可以读取上一镜的自然语言纲领来保持人物身份、剧情因果、环境时间线和整体美术连续，但当前镜头可以有自己的主体、构图和运镜，不需要继承上一镜头尾帧。提示词只需让动作在交付区内形成清楚的开始和结束；模型安全区由后期裁掉，不把安全区写成剧情。

### `long_take`

后段必须承接前段尾帧的六项状态：主体身份、身体姿态、空间位置、镜头构图、运镜方向与速度、光线与环境状态。当前镜头的定义是“从上一镜成片尾态继续生成下一段”，绝不是“描述上一镜的结束”。开头先明确“继续”而不是重新建立场景；动作从已有相位向后发展，不重复上一段已经完成的动作。上一镜刚通过校验的 H3 提示词是续写硬依赖：单镜生成时为空就先提示用户完成上一镜；批量生成时上一段失败则当前段及其后续连续段依次跳过，直到下一个硬切或叠化边界才恢复生成。

实际由上一段视频继续生成时，在 Ref2VA 中使用符合事实的 `video continuation`，并引用对应 `<Video N>`。同一链建议不超过三个生成窗口；超过时提醒画质和身份逐段劣化，但不擅自修改用户规划。

上游段重做后，下游段通常必须跟随重做，因为续接起始帧已经改变。

### `crossfade`

叠化是后期操作。两侧生成各自独立，但重叠区应尽量具备可混合条件：相近的主体屏幕位置、兼容的明暗关系、同向或可解释的运动、不过度突变的动作速度。叠化区内避免突然遮挡全画面、闪光过曝、瞬间大幅变焦或主体完全换边，除非这些正是用户想要的转场设计。

不要把“后期叠化 N 帧”翻译成 H3 必须渲染透明度混合。只描述两侧镜头各自应该达到的头尾状态；具体 `duration_frames`、安全帧和绝对点位由 Planner 与剪辑链路执行。

## 全片连续性

在所有镜头中保持项目总控定义的身份、服装、场景物理关系、色调、镜头质感和时代设定。只有当前镜头绑定的资产可以成为硬参考；未绑定资产即使存在于总资产库，也不能被写入当前镜头。

硬切允许镜头语言变化；长镜头要求时空连续；叠化要求两侧可混合但不要求同一场景。不要为了“连续”把所有镜头写成同色同景，也不要为了“节奏”无理由重置人物身份和空间方向。

## 明确删除的官方字幕分支

本项目不执行下列内容：

- Typography reference 或 Typography card。
- `Typography:` 字段。
- 歌词砸屏、空间歌词、动态字效、卡拉 OK 字或字幕排版。
- 缺歌词时自动创作歌词。
- Typography Motion Stitching。
- 把歌词语义自动变成可见文字、标牌或标题卡。

歌词仍可作为隐藏的时间语义、表演和口型依据。
